## Statically linked MinGW-w64 runtime components

The release executables statically link the GCC runtime libraries,
MinGW-w64 runtime, and winpthreads from the pinned x86_64 MinGW-w64
GCC 15.1.0 UCRT toolchain. They do not require
MinGW runtime DLLs at execution time.

The applicable notices are distributed in the binary package's
`licenses/` directory and in the source tree at `third_party/licenses/`:

- `GCC-RUNTIME-LIBRARY-EXCEPTION.txt` (GCC Runtime Library Exception 3.1;
  the GPLv3 text is also in `LICENSE`)
- `MinGW-w64-runtime.txt`
- `winpthreads.txt`

## Windows system libraries

The executables use Windows system APIs including Winsock (`ws2_32.dll`), CNG (`bcrypt.dll`) and the console/user interface APIs (`kernel32.dll`, `user32.dll`). These are supplied by Windows and are not redistributed in the package.
